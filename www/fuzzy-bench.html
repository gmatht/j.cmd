Fuzzy-match → fragment shader: GPU score matrix, chunked, texture-window, compile-once template

The per-offset fuzzy matcher is a fragment shader: one pixel = one haystack offset x, computing score[x] = Σ|needle[i] − haystack[i+x]|. Two data paths (src/fuzzygpu.js):

  • chunked — the needle chunk inlines per pass (ARR_CAP 1024; one cold compile per chunk), the haystack comes inline (≤ 1024) or as an uploaded texture (> 1024);
  • template — BOTH the needle and the haystack are uploaded textures (uTex + uCrack via the cr_* bridge), and the per-chunk window (uNeedleLen/uNeedleStart) + the offset tile (uTileStart) are uniforms: ONE compiled shader runs every chunk of any needle — the per-chunk cold-compile cost is gone (the needle loop bound is a dynamic uniform; verified on ANGLE/SwiftShader — ES 1.00 static-bound caveat for very old mobile is documented in §6f).

Either way: per-pass partial ≤ INT_MAX → the RGBA buffer can never overflow; the CPU reduces and argmins.
