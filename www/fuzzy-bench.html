Fuzzy-match → fragment shader: GPU score matrix + readback, chunked, texture-window

The per-offset fuzzy matcher is a fragment shader: one pixel = one haystack offset x, computing score[x] = Σ|needle[i] − haystack[i+x]|. The needle is chunked from the integer precision and the data domain (CHUNK_SIZE = floor(INT_MAX/MAXDIFF)); the haystack comes from one of two src/fuzzygpu.js load paths:

  • inline — the haystack is an inline array (backend cap ARR_CAP = 1024);
  • texture — the haystack is an uploaded W×H RGBA texture, and the liftTextureWindowSample transform rewrites every tex_r read into a per-use sample at the program-set tex_idx — the backend emits NO sample for loop reads, this is the gap the transform fills. Haystack lengths up to the texture capacity (~16384·rows).

Either way: one draw per needle chunk emits the partial score RGBA-packed, the CPU reduces (the total can never overflow the 32-bit buffer: per-pass partial ≤ INT_MAX), and the argmin is exact.

score channel: each pixel's RGBA = the 32-bit score (packed little-endian by the pack transform; A≥128 = unrepresentable sentinel — the chunk bound makes it impossible).
