Fuzzy-match → fragment shader: GPU score matrix + readback, chunked

The per-offset fuzzy matcher is a fragment shader: one pixel = one haystack offset x, computing score[x] = Σ|needle[i] − haystack[i+x]|. Two pipelines, same generator (src/fuzzygpu.js):

  • single-pass — the whole needle inline, every offset parallel in one draw;
  • chunked — the needle is broken into CHUNK_SIZE pieces sized from the integer precision and the data domain (CHUNK_SIZE = floor(INT_MAX/MAXDIFF), capped by the backend's array cap), one draw per chunk emits the partial score RGBA-packed, and the CPU reduces. Per-pass partial ≤ INT_MAX → the RGBA buffer can never overflow, at any needle length.

Backend limits this harness respects: the inline haystack array is capped at ARR_CAP = 1024 digits (past that the backend writes out of bounds), and the offset canvas at the texture-size limit.

score channel: each pixel's RGBA = the 32-bit score (packed little-endian by the pack transform; A≥128 = unrepresentable sentinel — the chunk bound makes it impossible).
