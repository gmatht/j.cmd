GCC-compiled C vs the browser iGPU (WebGL shader path)

Each problem is a HANDWRITTEN C reference compiled with gcc -O2 and run at a fixed size per problem (collatz 100M, ca1d 1B, hash 1B — reproducible, not calibrated to a wall time). The browser then runs the same problem at the same size through the sh2runtime WebGL path — a block reduction: each shader invocation processes BLOCK items and outputs a partial checksum, so the readback is N/BLOCK values instead of N (that is what keeps the GPU side fast). This page compares the two: wall time, speedup, and a mod-232 checksum that must match the C binary's output.
